# YouTube Фикс

Chrome-расширение, которое решает проблему «YouTube не открывается» без изменения системных настроек и настроек браузера вручную.

Расширение работает через стандартный API `chrome.proxy`: по переключателю оно направляет трафик браузера на локальный SOCKS5-прокси (`127.0.0.1`) вашего VPN-клиента, а при выключении возвращает системные настройки. Порт прокси можно указать вручную или доверить расширению поиск — просто вставьте конфиг своего клиента (JSON), и расширение само найдёт нужный `socks`/`http` inbound и его порт.

Всё происходит локально: никаких внешних серверов, телеметрии и посредников — трафик идёт напрямую через ваш клиент.

## Возможности
- 🔄 Один переключатель — включил/выключил, состояние запоминается.
- 🔍 Автопоиск настроек: вставьте конфиг VPN-клиента (JSON) — расширение само найдёт SOCKS/HTTP-порт.
- 🤝 Совместимость: Happ, INCY и любой клиент с локальным SOCKS5-прокси.
- 🛡️ Системные настройки прокси не изменяются — работает только внутри браузера.
- ⚙️ Manifest V3, service worker, минимальные права: `proxy` и `storage`.

## Установка
1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions/`.
3. Включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку с файлами.

## Использование
1. Нажмите на иконку расширения.
2. При необходимости вставьте конфиг вашего VPN-клиента в поле настройки — порт определится автоматически.
3. Включите переключатель — YouTube снова работает. Выключите — всё вернётся как было.
